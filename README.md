# the-public-advocate

## Choge Advocates | Corporate Law Web Application

A high-performance, fully responsive multi-page web platform built for a commercial and corporate law firm using clean semantics, Bootstrap 5, and native JavaScript.

## Platform Overview

This web application serves as a digital headquarters for a modern law firm, providing prospective shareholders with access to legal resources, advocate profiles, and consultation intake channels.

- **Live Deployment:---> (https://lennytrea.github.io/the-public-advocate/)
- **Target Environment:** Desktop.

## Technology Stack & Standards

- **Markup & Structure:** Semantic HTML5 compliance
- **Styling & Layout:** CSS3 custom properties integrated with Bootstrap 5 components
- **Interactivity:** Object-oriented JavaScript (ES6+) for form control.

## Application Architecture

The platform is composed of 8 structurally unified, interlinked modules:

1. `index.html` (Home) – landing page, core pillars, and strategic insights.
2. `about.html` (About Us) – Institutional history, mission statement, and corporate governance values.
3. `team.html` (Our Advocates) – Professionals, practice focus, and profiles of managing partners.
4. `services.html` (Practice Areas) – breakdown of corporate, intellectual property, and conveyancing services.
5. `blog.html` (Legal Insights) – Industry leadership, regulatory updates, and compliance.
6. `cases.html` (Notable Matters) – Summary tracking of high-impact transactions and dispute advisory cases.
7. `careers.html` (Careers) – Academic pipelines, pupillage pathways, and associate career opportunities.
8. `contact.html` (Consultation) – Multiple communication channels for clientele.

## Integrated JavaScript Features

- **Client Intake Validation Engine:** A robust client-side validation script handling real-time data cleansing, format evaluation, and user feedback UI strings on the contact.html page.
- **Interactive Matter Registry Filter:** A custom data-attribute filtering mechanism allowing users to separate past legal case studies by practice domain without a database.
